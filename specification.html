TELOP STUDIO / PRODUCT SPECIFICATION / 2026-10-16

文字で、動画を伝える。

無料の動画編集ソフトの文字装飾を補う、透過PNGテロップメーカー。単体の制作と台本の一括生成を同じ画面で行う。

アプリ · 完成後の操作マニュアル

1. 実行・公開

HTML / CSS / JavaScript ES Modulesのみ。ビルド不要。GitHub PagesまたはローカルHTTPサーバーで実行する。Google FontsとJSZipはCDN読み込み。アカウント登録不要。台本と設定はブラウザのLocalStorageに保存する。GitHubへの公開作業は対象リポジトリが決まった後に行う。

2. 画面構成

3. 台本・役割・編集

1カード＝1枚の画像。空から入力できる。貼り付け台本は空行で分割し、カード内改行は画像内改行として維持。自動折り返しはしない。A:／Ａ：はメイン、B:／Ｂ：はツッコミ、N:／Ｎ：はナレーション、※は注釈、!／！はタイトル。記号は除去し、※だけ残す。無指定はA。

1文字単位でフォント、サイズ、単色／縦グラデーション、3重フチ、影を上書きできる。座布団と文字揃えは画像単位。文字選択後も選択範囲を維持し、編集対象を表示する。手動装飾が自動強調より優先。強調解除は自動強調も無効にし、役割に戻す操作で再有効化する。

5. 描画・出力

Canvasに座布団→影→フチ3→フチ2→フチ1→文字を描く。lineJoin='round'、miterLimit=2。サイズの違う文字はベースラインを揃え、改行と左／中央／右揃えに対応。自動強調は数字＋単位・感嘆符・『』【】の範囲。ON/OFF、倍率、色を設定可能。

描画後に全画素のアルファ値>0を走査し、可視領域を抽出。透明な12pxの安全余白を新しいCanvasに加える。作業Canvasは実測した文字・フチ・影の範囲に余白を確保する。極端な寸法は描画前にエラー表示する。

PNG単体保存、Clipboard APIによるimage/pngコピー、JSZipによる連番ファイル一括保存。例：001_A_こんにちは.png。コピー成功を通知し、権限拒否や非対応時はPNG保存を案内する。直接貼り付けが編集ソフトで受理されることは別途検証対象。Clipchampを主な確認先とする。

6. プロジェクト・履歴

名前付きプロジェクトに台本・役割・個別装飾・役割設定・選択行を自動保存。プロジェクト／マイセットをJSONとして書き出し・読み込みできる。読み込みは検証し既存プロジェクトと別に追加。保存容量不足は画面で知らせる。

プロジェクトごとに直近50操作をメモリ内に保持。戻る／やり直す、履歴一覧からの復元。連続入力・スライダードラッグはまとめる。再読み込み後は最新の保存状態のみ復元。

7. ファイル

index.html / style.css / js/main.js / js/presets.js / js/parser.js / js/renderer.js / js/exporter.js。付属ドキュメントは本仕様書と、完成後に作成する操作マニュアル。

8. 完成確認

カード編集・部分装飾・セット適用・保存復元・履歴・JSON往復・PNG寸法と透明余白・ZIP内の連番PNGを確認する。ブラウザで画面とエラーを確認する。外部編集ソフトへの取り込みを実機確認できない場合は、その制限を明記する。

Ver1.1 追加仕様（2026-10-17）

右パネルに見本付きフォント一覧。フォントファイル（TTF/OTF/WOFF/WOFF2、1ファイル30MB以下）をFontFaceで読み込み、IndexedDBに保存。PCフォントはLocal Font Access APIによる一覧取得、または名前登録で追加。JSONにはフォント名だけを含む。全カード・全役割へのフォント適用は文字単位のフォント指定も統一し、編集履歴で戻せる。サンプルデザインは下部に折りたたみ、適用時に既存フォントを維持する選択肢を追加。追加フォント管理用にjs/fonts.jsを新設。

Ver1.2 追加仕様（2026-10-17）

塗りON/OFF、各フチの外側・中央・内側、ラウンド／マイター／ベベル結合、マイター比率1〜10、線端バット／丸型／角型、背景の全行／行別を追加。線端は閉じた文字輪郭では通常差が出ないことをUIで明示。文字マスクにより内外を分離し、透明な中抜きと影を合成。新設定は部分装飾・保存・履歴・JSONに対応。旧データには互換初期値を適用。

Ver1.3 / 間隔と座布団の配置

「字間」は文字と次の文字の間隔です。マイナスで詰められ、選択した文字だけにも適用できます。末尾には余分な字間を付けません。「行間」はカード全体・役割に適用され、影の大きさとは独立しています。どちらもスライダーと数値入力で調整でき、↺で0に戻せます。極端なマイナスでも文字・行の送りが逆転しないよう最小1pxを確保します。

「座布団・配置」では上下左右の余白を個別に設定し、9個の配置ボタンで文字を座布団内の左上・中央・右下などに揃えます。「文字揃え」は複数行の文字同士の揃え方です。「サイズ・位置の詳細」で座布団の自動サイズ／固定サイズ、幅・高さ、文字のXY移動を調整できます。固定サイズでも文字がはみ出せば切り捨てず出力します。最終PNGは影・フチを含む可視範囲に12pxを足してトリミングするため、固定した座布団サイズとPNG寸法は異なります。

影は方向と不透明度も指定できます。0°が右、90°が下、180°が左、270°が上です。不透明度0では文字やフチを残して影だけが消えます。旧データの影は元の位置を維持して読み込みます。行間の初期値は24pxとなり、旧版の影に応じた行間とは変わる場合があります。

装飾を別のカードにコピー

右上の「装飾をコピー」で現在のカード全体の装飾を記憶し、貼り付け先を現在のカード／チェックしたカードから選びます。文章と役割は変えません。文字単位の装飾はコピー元から移しません。「部分装飾を残す」がONなら貼り付け先の部分装飾を維持し、OFFなら解除します。貼り付けは「戻る」で取り消せます。コピー内容は再読み込みで消えます。

チェックしたカードだけ保存

左のカードにチェックを入れ、「チェックした○枚をZIP保存」を押します。元のカード順と番号を保持します。例えば2枚目だけなら002から始まるPNGを出力します。「全件ZIP」は従来どおり全カードが対象です。

Ver1.4 / 台本を順に仕上げる

左はカード一覧、文章の入力は中央に一本化しました。左の文章をクリックして選び、中央で修正します。中央の「話者」で役割を選び、「話者のデザインを編集」で右の共通設定へ進みます。例外の1枚だけ変えるときは「このカードだけ調整」を押します。

文字をドラッグしても右の編集対象は変わりません。入力欄の下の「重要」（赤＋拡大）、「小さく」「大きく」、色ボタンで部分装飾できます。さらにフチやフォントを変えたい場合だけ「部分装飾の詳細」を開きます。選択中の文章を表示し、連続操作後もハイライトを維持します。

  • 「前へ／次へ」または入力欄でAlt+↑・↓：カードを切り替えます。
  • 「＋ 同じ話者で追加」またはCtrl+Enter：現在の直後に空のカードを追加します。役割の基本デザインを使い、個別設定はコピーしません。日本語変換中は実行しません。
  • 「カーソル位置で分割」：文章の途中で2枚に分けます。役割、カードの設定、文字単位の装飾を引き継ぎます。
  • 「次のカードと結合」：次の文章を改行でつなぎ、文字単位の装飾を保持します。話者や基本デザインが異なる場合は確認し、現在のカードの設定に揃えます。

分割・結合・追加は「戻る」で取り消せます。端での分割、300枚を超える追加、5000文字を超える結合は実行しません。

色とアピアランスの操作（Ver1.5）

色選択は基本色・使用した色・お気に入りの共通パレット。色履歴とお気に入りはブラウザ別に独立保存し、JSONへ含めない。HEXと任意色選択に対応。新規プロジェクトは原則1層のフチから開始（注釈はなし）し、最大3層まで追加可能。既存の複数層は維持する。文字間フチ結合は初期OFF。ON時は層別にまとめ、外側を文字の後ろ・内側を文字の手前に描画して重なりの境目を除去する。影方向は8方向の矢印と角度数値。座布団ON/OFFは、折りたたみ式の座布団設定の先頭へ配置。「フチの角の形」は輪郭の曲がり方であり、マイター比率はマイター時だけ操作可。閉じた文字に作用しない線端UIは省略。

設定セクションを個別に開閉可能とし、開閉状態はブラウザに保存。文字のみ初期OPEN、他は初期CLOSED。テロップ・編集対象変更で開閉状態を維持する。座布団チェックボックスは座布団セクション内に配置。

ショート動画プレビューと追加フォント（Ver1.6）

単体／9:16を切り替える。9:16は1080×1920を基準に、表示用Canvasのみを位置・倍率指定で配置。ドラッグ、上下中央配置、倍率調整、横幅縮小、余白ガイド、矢印キー移動に対応。表示設定はブラウザに保存し、PNG・ZIP・画像コピー・プロジェクトJSONには影響させない。源ノ角ゴシックHeavy（SourceHanSans-Heavyの公式日本語優先Pan-CJK版）をOFL 1.1のライセンスとともに同梱し、必要時に読み込む。

01 / 起動する

GitHub Pagesで公開したURLを開けば、そのまま利用できます。ビルド・npm・Node.jsは不要です。Google FontsとJSZipをCDNから取得するため、インターネット接続が必要です。

ローカルでは、Pythonがインストールされている場合、同梱の start-local.cmd をダブルクリックします。ブラウザで http://localhost:8766 を開き、終了時はサーバーのウィンドウで Ctrl+C を押します。

手動で起動する場合は、アプリのフォルダーで次を実行します。

python -m http.server 8766 --bind 127.0.0.1

ES Modulesを使うため、index.html のダブルクリック（file://）では動きません。仕様書とこのマニュアルは、単独のHTMLとして開けます。localhostと127.0.0.1、ポート違い、GitHub公開URLはそれぞれ別の保存場所です。作業を移すときはJSONを使ってください。

02 / まず1枚作る

  1. 上部の「＋ 新規」でプロジェクトに名前を付けます。空のカードが1枚できます。
  2. 中央の「選択中のテロップ」に文字を入力します。Enterで画像内改行できます。
  3. 左のカードのプルダウンで役割を選びます。
  4. 右のフォント一覧から書体を選びます。配色も変える場合は、下部の「サンプルデザインを試す」を開き、サンプルを選んで「当てる」を押します。
  5. 「PNG保存 ↓」で透過画像を保存します。

初回起動時は、5枚のサンプルが入った「はじめてのテロップ」が表示されます。サンプルを直接編集しても構いません。

03 / 台本をまとめて入れる

左上の「台本をまとめて貼り付ける」を開き、入力後に「カードに追加」を押します。既存のカードは残り、末尾へ追加されます。

A: たった3つのヒントで
場所がわかる？

B: えっ、まさかの100万円！？

N: 『地形』に注目してみよう

※ 答えは最後に

! あなたは解ける？

空行が次のカードの区切りです。通常の改行は同じ画像内に残ります。カードを作った後は、中央の入力欄でいつでも編集できます。入力欄に文字装飾タグを直接書く必要はありません。

行頭役割画像上の扱い
A: / Ａ：話者A記号を除去
B: / Ｂ：話者B・ツッコミ記号を除去
N: / Ｎ：ナレーション記号を除去
※注釈※を残す
! / ！衝撃・タイトル先頭記号を除去
なし話者Aそのまま

行頭判定は一括取り込み時に行います。作成済みのカード内で「B:」などを入力しても役割は変わりません。役割はプルダウンで変更してください。

カード下部の「↑」「↓」で順序変更、「複製」で装飾ごとコピー、「削除」で削除できます。「全選択」と各カードのチェックは、セットや装飾の複数適用、選択分ZIPに使います。

編集対象は「役割の共通設定」から始まります。話者ごとの基本デザインはこちらで調整してください。「現在のカードだけ（個別設定）」では、そのカードだけが変わります。文字を選択しただけでは右の編集対象は変わりません。「部分装飾の詳細」を押したときだけ切り替わり、座布団・行間などは一時的に無効になります。「選択を終了」で装飾を残して元の編集対象へ戻ります。「強調解除」は装飾を外す操作で、選択終了とは別です。クイック装飾の後も文字の選択を保つので、赤→大きくなど続けて操作できます。

Ver1.4 / 台本を順に仕上げる

左はカード一覧、文章の入力は中央に一本化しました。左の文章をクリックして選び、中央で修正します。中央の「話者」で役割を選び、「話者のデザインを編集」で右の共通設定へ進みます。例外の1枚だけ変えるときは「このカードだけ調整」を押します。

文字をドラッグしても右の編集対象は変わりません。入力欄の下の「重要」（赤＋拡大）、「小さく」「大きく」、色ボタンで部分装飾できます。さらにフチやフォントを変えたい場合だけ「部分装飾の詳細」を開きます。選択中の文章を表示し、連続操作後もハイライトを維持します。

  • 「前へ／次へ」または入力欄でAlt+↑・↓：カードを切り替えます。
  • 「＋ 同じ話者で追加」またはCtrl+Enter：現在の直後に空のカードを追加します。役割の基本デザインを使い、個別設定はコピーしません。日本語変換中は実行しません。
  • 「カーソル位置で分割」：文章の途中で2枚に分けます。役割、カードの設定、文字単位の装飾を引き継ぎます。
  • 「次のカードと結合」：次の文章を改行でつなぎ、文字単位の装飾を保持します。話者や基本デザインが異なる場合は確認し、現在のカードの設定に揃えます。

分割・結合・追加は「戻る」で取り消せます。端での分割、300枚を超える追加、5000文字を超える結合は実行しません。

04 / 1文字からデザインを変える

  1. 中央の入力欄で、変えたい文字をドラッグ選択します。
  2. 入力欄の下の部分装飾ボタンが使えるようになります。右の編集対象は自動では変わりません。
  3. 「大きく」「赤」「黄」「青」で素早く変更するか、「部分装飾の詳細」を押してから右の詳細設定を変更します。

選択した文字だけのフォント・サイズ・グラデーション・3重フチ・影を変更できます。設定欄をクリックして入力欄のハイライトが消えても、最後に選択した範囲を保持します。画面の「○文字を選択中」を目印にしてください。

編集対象反映範囲
現在のカード全体今選んでいる1枚だけ。座布団・文字揃えもここで設定。
選択した文字選択範囲だけ。複数文字で設定が異なる場合、右欄には先頭文字の手動設定を表示。
役割の共通設定その役割を継承するカード。下の役割タブで対象を切り替える。

文字の個別指定 → カード個別設定 → 役割共通設定の順に優先します。自動強調よりも手動の指定が優先されます。例えば手動で色だけ指定した場合、自動強調のサイズ倍率は引き続き有効です。

「強調解除」は、選択範囲の手動装飾と自動強調を外します。「装飾を継承に戻す」は文字の個別指定を消し、カード／役割設定と自動強調を再び継承します。カード全体の「初期値に戻す」はカード個別設定を外し、役割の共通設定に戻します。文字単位の設定は別途解除してください。

文字を修正した場合、変更されなかった前後の文字の装飾は維持します。新しく入力・置換した文字は個別装飾なしで入り、カードの設定を引き継ぎます。

Ver1.1 / 自分のフォントを使う

右パネルに見本付きのフォント一覧が加わりました。クリックすると「編集対象」に指定したカード・文字・役割へ反映します。「このフォントを全カードに使う」は、全役割を更新し、カードや部分装飾のフォント指定も揃えます。色やサイズは残ります。「戻る」で取り消せます。

  1. 「＋ 自分のフォントを追加」を開きます。
  2. フォントファイルから追加する場合は、.ttf / .otf / .woff / .woff2 を選びます。1ファイル30MBまで。登録名はファイル名を基に付きます。
  3. PCのフォントを使う場合は「PCに入っているフォントから選ぶ」を押し、ブラウザの読み取り許可後に名前で検索します。対応しない環境ではフォント名を直接入力して追加できます。
  4. 追加後、一覧のフォントをクリックして適用します。

ファイルから追加したフォントはIndexedDBへ保存され、同じブラウザ・同じ公開URLで再利用できます。PCフォントは名前を保存するため、そのPCにインストールされている必要があります。JSONにはフォントファイル本体を含みません。別PCでは同じ名前のフォントを追加してください。削除用の「×」で一覧から外すと、そのフォントを使う文字は代替表示になります。フォントの追加・削除自体は編集履歴の対象外です。

サンプル適用時の「フォントは今のまま」は初期状態でONです。配色と装飾だけ変えたいときに使います。サンプルに指定されたフォントも使いたい場合はOFFにしてください。

05 / デザインセットとマイセット

「標準」「解説」「実況」「シリアス」「謎解き」から選び、適用先を「現在のカード」「チェックしたカード」「すべてのカード」から指定します。「部分装飾を残す」を外すと、対象カード内の文字単位の装飾も初期化されます。

セットを適用したカードには個別設定が付きます。その後で役割の共通設定を変えても、セットから適用した値が優先されます。共通設定に戻したい場合は、そのカードの編集対象を「現在のカード全体」にして「初期値に戻す」を押します。

「現在の5役割をマイセットに保存」で名前を付けて保存できます。役割の共通設定5つを保存し、現在のカードに個別設定があれば、そのカードの役割には現在の見た目を取り込みます。文字ごとの部分装飾はマイセットに含まれず、プロジェクト側に保存されます。

マイセットは同じブラウザ内の全プロジェクトで使えます。「マイセット書出」「読込」で別の環境に移せます。

Ver1.2 / アピアランスの調整

右の「文字」にある「塗りを表示」をOFFにすると、文字本体を消してフチだけを出力できます。塗りとすべてのフチをOFFにすると、文字の影も消えます。背景をONにすれば座布団だけを出力できます。

各「フチ1〜3」の「位置」で外側・中央・内側を選びます。外側は輪郭の外、内側は文字の中、中央は輪郭をまたいで描きます。同じ位置のフチは1から順に太さを積み上げます。位置が異なるフチ同士は別々に計算し、重なる場所では番号の小さいフチが手前になります。

「線の詳細設定」を開くと、角の結合をラウンド（丸い）・マイター（尖る）・ベベル（角を落とす）から選べます。「角の比率」はマイターが長く伸びすぎるのを制限します。線端はバット・丸型・角型を選べますが、フォントの輪郭は通常閉じているため、文字では見た目が変わらないのが正常です。

「座布団・配置」の「背景の範囲」は、すべての行をまとめて囲むか、1行ずつの文字幅に合わせて囲むかを選択できます。空の行には行別背景を描きません。行別の背景同士の間隔は行間で調整します。

塗り・フチ位置・角の設定は1文字単位にも適用できます。背景の範囲はカード全体または役割に適用します。各設定は履歴・プロジェクト・マイセット・JSONに保存されます。既存プロジェクトは、塗りON・外側フチ・ラウンド・全行背景を初期値として読み込みます。

Ver1.3 / 間隔と座布団の配置

「字間」は文字と次の文字の間隔です。マイナスで詰められ、選択した文字だけにも適用できます。末尾には余分な字間を付けません。「行間」はカード全体・役割に適用され、影の大きさとは独立しています。どちらもスライダーと数値入力で調整でき、↺で0に戻せます。極端なマイナスでも文字・行の送りが逆転しないよう最小1pxを確保します。

「座布団・配置」では上下左右の余白を個別に設定し、9個の配置ボタンで文字を座布団内の左上・中央・右下などに揃えます。「文字揃え」は複数行の文字同士の揃え方です。「サイズ・位置の詳細」で座布団の自動サイズ／固定サイズ、幅・高さ、文字のXY移動を調整できます。固定サイズでも文字がはみ出せば切り捨てず出力します。最終PNGは影・フチを含む可視範囲に12pxを足してトリミングするため、固定した座布団サイズとPNG寸法は異なります。

影は方向と不透明度も指定できます。0°が右、90°が下、180°が左、270°が上です。不透明度0では文字やフチを残して影だけが消えます。旧データの影は元の位置を維持して読み込みます。行間の初期値は24pxとなり、旧版の影に応じた行間とは変わる場合があります。

装飾を別のカードにコピー

右上の「装飾をコピー」で現在のカード全体の装飾を記憶し、貼り付け先を現在のカード／チェックしたカードから選びます。文章と役割は変えません。文字単位の装飾はコピー元から移しません。「部分装飾を残す」がONなら貼り付け先の部分装飾を維持し、OFFなら解除します。貼り付けは「戻る」で取り消せます。コピー内容は再読み込みで消えます。

チェックしたカードだけ保存

左のカードにチェックを入れ、「チェックした○枚をZIP保存」を押します。元のカード順と番号を保持します。例えば2枚目だけなら002から始まるPNGを出力します。「全件ZIP」は従来どおり全カードが対象です。

06 / 細かいデザイン設定

  • 文字：内蔵5フォント＋追加フォント、12〜240px、単色または上下グラデーション。
  • フチ：各層でON/OFF・色・太さ・位置を指定。同じ位置では1から順に太さを積み上げます。
  • 影：ぼかし・距離・方向・不透明度・色を設定。
  • 座布団：背景色・不透明度・角丸・内側余白・枠線。枠線にも設定した不透明度が適用されます。
  • 文字揃え：複数行を左・中央・右で配置。長い文章は自動折り返ししないため、入力欄で改行してください。
  • 自動強調：100万円・99%・3つなど、感嘆符、疑問符、『』と【】で囲んだ箇所を検出。倍率と強調色を変更できます。

プレビューの「透過」「黒」「映像風」は確認用背景です。PNGには背景を含めず、座布団を有効にした場合だけ指定した背景ボックスが含まれます。

07 / 保存して動画編集ソフトへ

単体PNG

中央の「PNG保存 ↓」で現在の1枚を保存します。出力画像にはフチと影を含め、可視部分の周囲に12pxの透明余白を付けます。文字数やデザインにより画像寸法が変わるため、編集ソフトでは位置と倍率を確認してください。

全件ZIP

上部の「全件ZIP ↓」で、カード順に連番を付けてまとめます。ZIPを展開してから編集ソフトへ読み込みます。出力開始時点の台本を使うため、出力中の編集はそのZIPへ反映されません。

001_A_たった3つのヒントで.png
002_B_えっ、まさかの100万円！？.png
003_N_『地形』に注目してみよう.png

タイトルの役割名はTITLE、注釈はNOTEで出力します。ファイル名に使えない記号は除去します。

画像コピー

中央の「この画像をコピー」、左のカードの「▣」、サムネイルの「コピー」からPNGをコピーできます。HTTPSまたはlocalhostの対応ブラウザが必要です。ブラウザの権限を求められた場合はコピーを許可してください。

ブラウザの画像コピー成功は確認済みですが、Clipchamp／Premiereへの直接Ctrl+V取り込みは実機未検証です。貼り付けを受け付けない場合はPNG保存を使ってください。

Clipchampで使う

  1. PNGを保存します。一括ZIPの場合は展開します。
  2. Clipchampの「メディアのインポート」からPNGを読み込みます。
  3. 映像より上のトラックへ画像を配置します。
  4. 画面内の位置・大きさ・表示時間を調整します。

画像をインポートして映像の上に重ねる流れは、Microsoft公式の画像配置手順に基づきます。今回、ユーザーのClipchampプロジェクトを操作しての取り込み確認はしていません。

08 / 保存・バックアップ・履歴

変更は短い待ち時間の後にブラウザへ自動保存されます。プロジェクト切り替えは上部の名前欄から行います。ブラウザのデータ削除や別ブラウザへの変更では保存データを引き継げません。

  • JSON保存：現在のプロジェクトとマイセット一覧を書き出します。画像だけでなく、後から装飾を編集できる状態を保存します。
  • 読込：プロジェクトを新しい項目として追加します。既存のものを上書きしません。
  • ↶ / ↷：戻る・やり直す。WindowsではCtrl+Z、Ctrl+Shift+ZまたはCtrl+Yも利用できます。
  • 履歴：一覧から戻したい状態を選べます。直近50操作とその前の基準状態を保持します。

連続入力と短時間の同じスライダー操作は1操作にまとめます。履歴はプロジェクトごとに保持しますが、アプリを再読み込みすると最新状態だけが残ります。プロジェクト新規作成・切り替え、マイセット登録、JSON読み込みは編集履歴の対象外です。

09 / 困ったとき

状況対処
操作が反応しないfile://ではなくHTTP/HTTPSで開いているか確認。JavaScriptを有効にする。
フォントが違うインターネット接続後に再読み込み。CDNが遮断される環境では代替フォントになる。
役割の色を変えても反映しないカードや文字の個別設定が優先されていないか確認。必要な範囲だけ継承へ戻す。

画像が大きすぎる改行、文字サイズ縮小、カード分割。作業Canvasは一辺16384px・総面積2400万画素以内。

上限はプロジェクト100件、1プロジェクト300枚、1枚5000文字、マイセット100件、読み込みJSON 20MBです。実際にブラウザへ保存できる量は環境の容量制限にも依存します。

10 / 確認したこと

Ver1.3では正負の字間・部分字間・行間、9方向配置、固定サイズと文字のはみ出し、XY移動、影の方向と不透明度、旧版データの移行、装飾貼り付けと取り消し、選択ZIP、保存復元をChromeで検証しました。

Ver1.2ではフチ位置による実際の画像寸法の違い、内側フチの中抜き、塗り・フチOFF時の不要な影がないこと、角の結合による画素差、マイターの見切れ防止、行別背景の範囲、透明余白12px、設定の保存復元・JSON保持を検証しました。既存の編集・フォント追加・PNG／ZIP出力の回帰テストも通過しています。

Ver1.1ではChromeで実フォントファイルの読み込み・IndexedDBからの復元・フォント名のJSON維持・全カードへの変更と取り消し・サンプル適用時のフォント保持・破損フォントの拒否・PCフォントの実一覧取得と検索を確認しました。
